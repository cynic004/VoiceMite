# 实现与安全边界

## 分层

- `VoiceMite.Core`：独立 STT/LLM 配置、HTTPS 请求、长度限制、结构化输出校验、场景策略、会话代次与取消、非敏感设置/偏好存储。
- `VoiceMite.Windows`：winmm 录音、DPAPI 用户范围密钥文件、Win32 窗口/权限检查、UI Automation 控件与选区检查、剪贴板兼容粘贴。
- `VoiceMite.App`：WPF 悬浮图标、面板、设置、资源化中英文文案、托盘和生命周期管理。

## 数据路径

```text
用户点击开始 → 麦克风 PCM（内存）→ 停止 → WAV → 已配置 STT
  → 转写原文 → 只转写/原文：直接预览
             → 其他模式：已配置 LLM → 严格解析 → 预览/澄清
  → 用户确认 → 验证原输入目标 → 一次粘贴 / 保留供手动复制
```

目标指纹仅用于本地验证，不参与模型上下文。没有屏幕截图、浏览器历史、聊天历史采集或远端工具调用。模型输出仅能成为待预览文字。

跨进程 UI Automation 在独立 STA 工作线程运行，并设置等待上限；控件挂起或超时后安全拒绝，不让界面线程长期阻塞。Windows 工作线程的模拟检查与真实控件插入检查分开报告。

## 状态与请求隔离

待机、录音、转写、整理、澄清、待插入、错误与取消分开管理。每个新任务增加代次并取消前一个任务；异步结果必须仍属于当前代次才可更新界面。取消先使代次失效，再向外部请求发送取消，防止服务忽略取消后晚到结果覆盖新内容。请求取消不保证服务端免于计费。

当前真实音频接口为非流式。音量/时长是录音反馈，不标记为转写；不显示虚构“已理解内容”。实时能力如果未来加入，临时结果必须单独标识且不得成为可自动插入结果。

## 输入安全

抓取原目标的窗口、进程、控件及选区指纹。只有同一目标、可编辑、权限兼容、非敏感且输入位置可证明未变时才尝试兼容粘贴。TextPattern 用于读取/比较，禁止将 ValuePattern 全量覆盖视作追加。

程序不持有跨系统窗口的事务锁，因此验证与粘贴之间仍存在系统调度和用户操作的竞争窗口。实现尽量在发送前重新检查并拒绝异常状态；不能把这称为对所有应用的绝对安全保证。结果不确定时不重试。

剪贴板有外部工具和延迟渲染风险。备份失败则拒绝自动插入；恢复前检查当前序列号，用户新复制后不恢复旧数据。Windows 剪贴板历史和第三方管理器不受程序控制。

## 费用与配置边界

STT、LLM 分别验证，分别保存加密密钥。没有后台待机请求、无限重试或摘要请求循环；用户主动录音/整理/连接测试才发送相应请求。HTTPS 证书正常校验，拒绝自动重定向。接口返回原始错误体不直接显示或记录，以免服务商将凭据回显。

普通 JSON 不含密钥，偏好只有用户可解释的小字段。用户确认文字后仅提取标点、长度等特征，不保存完整确认文字。删除偏好文件是功能删除，不声称对存储设备、备份、云同步或模型服务端完成安全擦除。
